# 레미 공격 모션 "코어 방출" — 작업 기록 (작업 폴더, Assets 밖, Unity 미적용)

## 1. 요청과 범위 (2026-10-16)
- 사용자 지정 모션: **코어 방출** — 몸을 살짝 웅크리고 양팔을 벌림 → 가슴 코어에 빛이 모임 → 화면 오른쪽으로 짧은 마법탄 발사 → 복귀. "필요하면 VARCO 워크플로우 이용".
- 제작·미리보기까지. **사용자 승인 전에는 Unity 에셋·Animator·프리팹·씬·전투 코드를 바꾸지 않는다.** 커밋 안 함.

## 2. 확인한 사실
- 레미 = 씬의 `Player/Golem1_3_0`(루트 배율 0.3) 아래 `P_GolemIdle`(Animator `GolemIdle`, 상태 하나) → `BodyFeet`(→`ChestCore`→`Art` 가슴 코어 스프라이트 `ChestCore_Off`), `Head`(→눈꺼풀 둘), `LeftArm`, `RightArm`. 파츠 스프라이트 PPU 100, 화면 환산 1로컬 = 32.4px, 텍스처 1px = 0.324 화면 px. 레미는 화면 x 276~366, y 148~269(약 90x120px), 정면 대칭, **도트 한 칸 ≈ 3 화면 px**. 가슴 코어는 약 14px(화면 (327,214)~(342,228)), 레미 왼쪽 가슴.
- 기존 `GolemIdle/Lemy_Attack.anim`(0.5초, 머리·팔 위치 곡선)이 있지만 컨트롤러·코드 어디에도 연결 안 된 미사용 클립. 게임에는 레미 공격·피격 연출이 없고, 코어는 `Art` 스프라이트가 정적으로 Off.
- 아트 가이드(codex worktree `Tetrigeon_Pixel_Art_Guide_EN.md`): 번지는 외곽 빛·임의의 청록 점 입자 금지, 단단한 도트, 팔레트는 승인된 에셋에서 샘플링. 코어는 켜진 상태(청록 구슬 + 흰 하이라이트)가 기준.

## 3. VARCO
- 이 세션에는 VARCO 도구가 연결돼 있지 않아 사용하지 못함(사용자에게 알림). 이번 모션은 레미 아트를 그대로 쓰는 파츠 이동이고, 이펙트는 투명 층이 필요해 VARCO(투명 출력 없음)로는 만들 수 없어 어차피 코드로 그림. 크레딧 0.

## 9. v2 수정 (2026-10-16, 사용자: "목 연결부 표시 부분과 머리가 그대로 이동하고 주먹 부분의 일부가 몸에 붙어있어서 AI티가 너무 난다")
- **원인 분석(파츠별 캡처 + 스프라이트 픽셀 분석)**: ① 목 청록 표시는 머리 스프라이트 아래 중앙(`Head` 276x190 의 (128~153, 181~189))에 있고 몸 윗면에도 작은 점(`BodyFeet` (80~89, 0~8))이 있음. v1 에서 머리를 몸 위로 6px 평행 이동하자 머리가 어깨에 파묻히면서 목 표시가 가슴 위에 떠 있었음. ② 어깨 연결 청록 빛(좌 (8~19,48~63), 우 (155~162,49~64))은 **몸 스프라이트에 그려져 있고 팔 스프라이트에는 없어서**(팔 청록 0) 팔을 벌려도 몸 가장자리에 남아 "주먹 일부가 몸에 붙은" 모습이 됨. ③ 머리를 그대로 평행 이동만 해서 기계적.
- **고친 방식**(`tools/lemy_poses.js`):
  - 웅크림 = 몸통을 발 기준으로 세로로 눌러(배율 0.93~0.94) 어깨선이 내려오고 머리·팔이 그 양만큼 따라 내려옴 → 머리가 몸에 파묻히지 않고 목 표시가 목 자리에 그대로 있음(발은 땅에 고정). 압축량 = 몸통 높이 61.9px × (1−s) → 약 4px.
  - 머리는 발사 때 **목을 축으로 오른쪽으로 5도 기울어짐**(평행 이동 아님), 몸이 위로 1.03배 펴지며 머리 3px 올라갔다가 반동으로 0.99배로 되눌림 → 숨 들이쉬고 내쉬는 느낌. 충전 중에는 몸이 0.93↔0.94 로 숨 쉬듯 살짝 오르내리고 팔이 3px 올라감(v1 의 "팔 떨림" 대체).
  - 어깨 연결 빛은 **팔을 따라가도록** 파생 스프라이트를 만듦(`tools/make_variants.js`, 코드로 만든 파생이며 원본 `T_GolemParts` 는 그대로): `BodyFeet_Open`(몸에서 좌·우 어깨 청록 조각과 어두운 청록 번짐을 가장 가까운 남색 윤곽색으로 메움, 598픽셀), `LeftArm_Glint`(81x191)·`RightArm_Glint`(75x191)(원래 팔에 그 조각을 기본 자세의 몸 위 자리와 똑같이 옮겨 붙임, 캔버스만 넓힘·피벗 픽셀은 원본 팔과 같음). 팔 정렬 순서를 몸(0)보다 앞(1)으로. 기본 자세에서 원본과 비교하면 다른 화면 픽셀이 33개(색차 큰 것 1개)뿐이고 눈으로는 같음(`work/variant_check`).
  - 팔 벌림은 ±9px → ±6px 로 줄임(떠 있는 느낌 감소).
- 이펙트는 프레임마다 실제 코어 위치(몸이 눌리면 코어도 내려감)에 맞춰 다시 그림(`work/core_centers.tsv` 는 Unity 캡처에서 측정). 이펙트 모양·색은 v1 과 같음.
- **산출물은 v2 로 저장** (`output/LemyCoreRelease_*_v2`). v1 이름 파일은 수정 중 같은 이름으로 덮어써져 내용이 v2 와 같아져 정리(원래 v1 그림은 이미 사용자에게 전달한 대화 속 이미지로만 남음). 추가: `..._Closeup_6scenes_x5_v2.png`(핵심 6컷 5배), `..._DerivedSprites_x3_v2.png`(원본↔파생 스프라이트).
- 검사(v2): 이펙트 팔레트 밖 0·3px 격자 어긋남 0·눈 겹침 0(머리 상자 기준)·체력바 겹침 0·가장자리 접촉 0, 포즈 값 3의 배수.
