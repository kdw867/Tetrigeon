# 몬스터 Idle 스프라이트 시트 공통 지침

사용자 확정 지침. Unity용 몬스터 Idle 제작 시 적용한다. 핵심은 디자인 일관성, 정확한 프레임 정렬, 절제된 제자리 움직임이다.
몬스터별 셀 크기·캔버스 크기·고정 기준점·이동 범위는 후속 개별 규격을 따른다. 아직 제공되지 않은 규격을 확정된 것으로 간주하지 않는다.

## 디자인 유지
- 첨부한 승인 원화의 실루엣, 비율, 결정 개수, 얼굴, 색상, 명암 방향을 유지한다.
- 보라색 수정과 청록빛 마력, 모서리가 살짝 둥근 네모난 결정, 계단식 블록 구조를 유지한다.
- 모든 프레임에서 살짝 왼쪽을 바라보는 3/4 시점을 유지한다.
- 움직이는 파츠는 동일 그림을 이동하거나 최소한 회전한다. 프레임마다 새로 해석하거나 다른 모양으로 다시 그리지 않는다.
- 수정의 크기·개수·균열·반사광 위치를 이유 없이 바꾸지 않는다.
- 작은 화면에서 읽히는 큰 픽셀 덩어리와 제한된 색상을 사용한다.
- 안티앨리어싱, 흐림, 부드러운 그라데이션, 혼합 픽셀 크기는 금지한다.

## 시트 규격
- 정확히 10프레임, 가로 5칸 × 세로 2칸.
- 윗줄 왼쪽부터 01~05, 아랫줄 왼쪽부터 06~10.
- 모든 셀은 동일 크기, 정확한 정수 픽셀 좌표로 배치한다.
- 셀 사이 간격, 테두리, 구분선, 숫자, 글자, 워터마크는 없다.
- 실제 알파 채널이 있는 투명 PNG. 체크무늬를 그림으로 넣지 않는다.
- 그림자, 바닥, 배경 장식은 없다.
- 최대 움직임에서도 모든 파츠는 셀 안에 남는다.
- 프레임별 자동 크롭이나 개별 리사이즈는 금지한다.
- 정확한 셀 크기와 캔버스 크기는 몬스터별 규격을 따른다.

## 좌표와 정렬
- 각 셀의 왼쪽 위가 (0, 0), X는 오른쪽, Y는 아래쪽으로 증가한다.
- 모든 지정 좌표는 전체 시트가 아닌 셀 내부 로컬 좌표다.
- 몸의 고정 기준점은 모든 프레임에서 동일한 픽셀에 위치한다.
- 변하는 외곽 바운딩 박스를 기준으로 매 프레임 다시 중앙 정렬하지 않는다.
- 고정 몸통·발·받침은 첫 프레임의 동일한 픽셀을 그대로 유지한다.
- 캐릭터 전체 좌우 이동, 전체 확대·축소, 카메라 이동, 시점 회전은 금지한다.
- 발이 있으면 발바닥 위치를 완전히 고정한다.
- 연결부가 찢어지거나 빈 사각형 구멍이 생기지 않게 한다.

## 루프와 움직임
- 10프레임은 짧고 자연스러운 하나의 대기 동작이다.
- 같은 그림 10장 복제로 프레임 수를 채우지 않는다.
- 극점에서 잠시 정지하는 동일 프레임은 허용하되, 움직임과 눈 상태 변화가 순서대로 읽혀야 한다.
- 10→01 연결에서 위치나 밝기가 튀면 안 된다.
- 과한 움직임을 느린 FPS로 숨기지 않고 실제 파츠 이동 거리를 작게 한다.
- 보행, 점프, 공격, 큰 몸 흔들기, 과도한 머리 숙이기는 금지한다.
- 빛 변화는 작은 코어 내부에만 적용한다. 몸 전체 밝기·색 깜빡임은 금지한다.

## 눈 표현
- 눈과 눈꺼풀은 얼굴에 붙어 함께 움직인다.
- 눈을 감을 때 눈 전체를 찌그러뜨리거나 얼굴을 변형하지 않는다.
- 위 눈꺼풀이 내려와 발광 영역을 가린다.
- 완전히 감긴 프레임에는 밝은 눈동자를 남기지 않는다.
- 기존 눈 윤곽 안에서 처리하여 검은 사각형 패치가 튀어나오지 않게 한다.

## 완성 전 검증
- 모든 프레임의 고정 기준점 좌표가 동일한지 확인한다.
- 첫 프레임과 비교하여 고정 파츠의 이동·변형이 없는지 확인한다.
- 의도한 파츠만 지정 범위 안에서 움직이는지 확인한다.
- 10→01 연결의 자연스러움을 확인한다.
- 실제 작은 표시 크기에서도 눈 감김과 움직임이 읽히는지 확인한다.

## 결과물과 제작 방식
1. 정확한 규격의 투명 PNG 스프라이트 시트.
2. 가능하면 같은 시트에서 만든 반복 재생 GIF 미리보기.
3. 셀 크기, 배열, 프레임 순서, 권장 FPS를 짧게 명시한다.

이미지 생성 도구가 정확한 픽셀 정렬·출력 크기를 보장하지 못하면 생성 결과를 원화로 삼아 코드 또는 이미지 편집 도구로 후처리할 수 있다. 후처리로 셀 규격·고정 좌표·파츠 정렬을 검증한다. 검증하지 못한 부분은 완료했다고 말하지 않는다.
