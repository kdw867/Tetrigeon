## 2. VARCO (사용자가 "2번 VARCO로 진행" 선택)
- 도구 확인: `GenerateImage`(참조 이미지 최대 4장), `EditImage`(원본+지시문), 3D 메시/휴머노이드 리깅/Animate. 6다리 2D 도트 애벌레에는 3D 쪽이 맞지 않아 이미지 편집만 사용. 이미지 1장 = 20크레딧 (nano-banana-2).
- 입력: 사용자가 에디터에 올린 승인 원화(ImageInput `c05c8d16…`)를 원본으로 `EditImage` 2개 사용. 새로 만든 노드: TextInput 2개(`479254b5…` 움츠림, `2189bcf5…` 타격), EditImage 2개(`0c869acb…` 움츠림, `3137a2ea…` 타격). 실행 범위는 이 2개로만 지정(범위를 비우면 에디터의 기존 110개 노드가 전부 다시 돌아 크레딧이 크게 나가기 때문).
- 1차(2장, 40크레딧): "세 마디는 같은 위치로 두고 살짝만" 지시. 마디 경계(윗선 골짜기) 상대 위치가 원화와 같음(0.393/0.470/0.681) → 마디가 움직이지 않았고 앞발 돌만 약간 달라짐. 참고 불가.
- 2차(2장, 40크레딧): 마디를 "폭의 1/4만큼" 크게 움직이라고 지시. 결과
  - 움츠림: **좌우 반전**(머리가 오른쪽을 봄). 지시문에 "미러링 금지"를 넣었는데도 뒤집힘 → 비대칭 수정 배치가 바뀌므로 사용 불가.
  - 타격: 머리 마디는 왼쪽으로 나갔으나 **머리가 커지고**, 마디 사이에 원화에 없는 **회색 돌 블록**이 생김 → 디자인 유지 조건 위반.
- 결론: 합계 4장, **80크레딧**. 시트에는 한 장도 넣지 않았다. 참고로는 "마디가 벌어질 때 아래 받침이 이어져야 한다"는 점만 활용. 원본은 `output/varco_attempts/`, 한 장 요약은 `output/VARCO_attempts_contact.png`.
- VARCO 에디터에 남은 것: 위 노드 4개(내가 만든 것)와 사용자가 올린 ImageInput 1개. 삭제하지 않았다.

## 3. 최종 제작 방식 (VARCO 없이 승인 도트 그대로)
- 기준: Idle 01(=09=10, 휴식 자세)을 마디 3개로 나눔: 머리 H(눈 있는 큰 마디) / 첫 번째 몸통 M(가운데) / 두 번째 몸통 R(뒤). 각 마디가 자기 다리·받침·수정을 모두 가진다.
  - 돔·받침(Y<47)은 X 27/39 경계, 다리(Y>=47)는 발 사이 틈 X 24/36 경계 → 수평 절단 없음, 발 돌이 두 조각으로 갈리지 않음.
  - 그리기 순서는 항상 뒤 몸통 → 가운데 → 머리.
  - 벌어질 때 드러나는 부분: 이웃 아래에 숨은 외곽선 2칸(원래 외곽선과 같은 색)을 미리 깔아 둠. 정지 자세에서는 가려져 보이지 않음. 마디 간격은 최대 2px.
  - 어긋나며 생긴 갇힌 틈(06에서 3칸, 07에서 2칸)은 이웃 색으로 채움. 검사는 채운 뒤 구멍 0칸이어야 통과.
- 파츠는 정수 픽셀 이동만 사용(회전·보간·확대 없음). 모든 프레임이 같은 셀·같은 기준점.
