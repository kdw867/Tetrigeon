## 1. LOCK
- 디자인: 고정된 칸 가장자리에 얇은 청록 테두리 → 점등(2px, 모서리 흰 점) → 약해지는 잔광 → 점선 → 모서리 점 → 소멸. 내부는 완전 투명, 파편 없음.
- 프레임: 0 밝음(2px) / 1 약간 어두움 / 2 더 어두움 / 3 1px / 4 점선 / 5 성긴 점선 / 6 모서리 점 / 7 빈 프레임
- 변형(행): 행 번호 = 노출된 변의 비트 합 (북 1, 동 2, 남 4, 서 8). 같은 미노끼리 맞닿은 변에는 테두리를 그리지 않아 인접 칸 경계가 겹쳐 밝아지지 않고, 미노의 바깥 윤곽만 빛남. 칸 수와 모양에 상관없이(4칸, 여왕 증식 5칸 이상) 칸마다 마스크만 계산하면 됨. 마스크 15 = 혼자 있는 칸.
- 기준점·배치: 셀 가운데(13.5, 13.5) = 칸 가운데, 월드 크기 0.25 (= `CellSize`)

## 2. LINE CLEAR
- 디자인: 가운데에서 좌우로 퍼지는 얇은 가로빛(흰 중심선 + 청록 가장자리 5줄) → 보드 폭 전체 → 얇고 어두워진 선 → 끊어진 점선 → 위아래로 조금 흩어지는 1px 입자 → 소멸. 채움 없음, 행 높이(27) 안에서만 흩어짐.
- 프레임: 0~3 폭 28/88/164/236으로 확산, 4 보드 폭 전체(270), 5 얇고 어두움, 6 점선, 7~8 입자, 9 빈 프레임
- 제작: 한 칸짜리 그림을 늘리지 않고 실제 보드 폭 270px 캔버스에서 직접 그림
- 기준점·배치: 셀 가운데(135, 15.5) = 삭제된 줄의 가운데(보드 가로 가운데, 줄 세로 가운데). 월드 폭 2.5 = 보드 폭. 줄마다 하나씩, 동시에 여러 줄이면 각 줄에 동시에.

## 3. 수정 칸 파괴 (공통 1종)
- 디자인: 가운데 흰·청록 점 → 네 갈래 별빛 + 작은 보라 파편 4개 → 보라 결정 파편 4개가 대각선 바깥으로 퍼지며 작아짐 → 청록 불씨 → 소멸. 파편 4개(3~5개 범위), 중심광 청록·백색, 파편 보라(결정 면 하이라이트 + 짙은 보라 외곽선). 능력별 색 변형 없음.
- 프레임: 0 점 / 1 별빛 + 작은 파편 / 2 파편 커짐 / 3~6 퍼지며 축소·소멸 / 7 빈 프레임 (VARCO 시트 1,2,3,5,6,7,8번 칸 사용, 파편이 8개인 4번 칸은 제외)
- 범위: 중심 기준 약 ±11도트 = 화면 ±22px (2배 표시 시 최대 약 44px = 1.6칸) → 54px 칸 안에서 잘리지 않음
- 기준점·배치: 셀 가운데(13.5, 13.5) = 수정 칸 가운데, 2배(PPU 54)로 표시하면 화면 54px

## 겹침 규칙 (미리보기에서 시연, Unity 연결 시 지킬 내용)
1. 삭제되는 칸에는 LOCK 없음(CLEAR 우선). 삭제 후 남는 고정 칸에는 LOCK을 보이되, 줄 삭제로 아래로 내려오므로 **블록의 압축 후 위치**를 따라가야 함.
2. 수정이 포함된 줄: 가로빛이 먼저 나오고 수정 파편은 약 3틱(0.06초) 뒤따름 — 연출 시간차만 사용, 피해·능력 처리 시간은 바꾸지 않음.
3. CLEAR·수정 파괴 위치는 `GridManager.ClearLines`가 블록을 지우기 직전의 (x, y)를 써야 함 (압축 전 좌표, 삭제된 블록 참조 사용 안 함). 수정 칸 판별은 기존 `MinoArtBinding.IsCrystal`과 `clearedCrystals` 기록을 그대로 따름 (여왕 증식 칸·가비지·애벌레·Top Out은 해당 없음).
4. LOCK은 `PieceSpawner.Lock()` 한 곳(자연 낙하·하드드롭 공통)에서 칸 목록(`boardCell`)으로 1회. Hold·이동·회전·고스트는 해당 없음.

## VARCO 사용 내역
- 기능 확인: 이미지 생성·편집, 이미지→3D 메시, 리메시, PBR, 리깅, 3D 애니메이션만 있음. 2D 스프라이트 애니메이션·투명 PNG 출력은 없어서 3D는 쓰지 않았고, 2D 이미지 생성(nano-banana-2, 16:9/4:3)으로 프레임 시트 3장을 만들어 디자인과 수정 파편 프레임에 사용.
- 생성 3장 = 60크레딧 (장당 20): `generated/crystal_v1.png`, `lock_v1.png`, `clear_v1.png` (초록 배경, 도트 한 칸 약 11.5px)
- 수정 파괴: 생성 프레임을 도트 격자에 맞춰 줄이고(초록 제거, 중앙값 색, 게임 팔레트로 정리, 프레임별 중심 정렬) 그대로 사용
- LOCK·LINE CLEAR: 생성 시트의 디자인(2px 테두리·흰 모서리·점선·태퍼 가로빛)을 따라, 생성 이미지가 칸·보드 폭에 정확히 맞지 않아(칸이 정사각형이 아니고 줄 폭 불일치) 코드로 정확한 규격에 다시 그림
- 도구: `tools/` (extract_crystal.js, build_crystal.js, build_lock_clear.js, prep_board.js, preview_fx.js, preview_single.js, contact.js, lib_fx.js)
